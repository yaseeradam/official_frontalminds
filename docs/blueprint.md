# **App Name**: FrontalMinds

## Core Features:

- Neon Gradient Hero Section: Implement a landing page hero section with a neon gradient headline and animated particle background.
- Kali-Linux Style Terminal Navbar: Integrate a global Navbar component with a Kali Linux-style mini terminal that supports commands like 'help', 'about', 'services', 'projects', 'contact', 'clear', and 'exit'.
- Command Router: Create terminal commands. The app will decide when to show/hide information to the user based on which tool has been chosen. Includes easter eggs when typing frontal or brain
- Service Showcase Grid: Display services in a grid with glowing borders and hover effects.
- Animated Page Sections: Use framer-motion for smooth animations on page sections and cards, including fade-in effects and neon hover glows on buttons and links.
- Sci-fi Contact Form: Create a sci-fi-styled contact form with glowing inputs and holographic icons, or a 'Connect Terminal'.
- Responsive Layout: Ensure the website is fully responsive and mobile-first, adapting to different screen sizes and devices.

## Style Guidelines:

- Primary color: Neon cyan (#06B6D4) for accents and interactive elements, providing a futuristic feel.
- Background color: Dark background (#0B0F19) to enhance the neon glow and provide contrast.
- Accent color: A slightly lighter shade of cyan (#41E2FF) for highlights and hover effects to draw attention.
- Headline font: 'Orbitron' (sans-serif) for a futuristic, tech-inspired look in headings. Note: currently only Google Fonts are supported.
- Body font: 'Inter' (sans-serif) for clean and readable body text. Note: currently only Google Fonts are supported.
- Code font: 'Roboto Mono' (monospace) for terminal text and code snippets. Note: currently only Google Fonts are supported.
- Subtle fade-in animations and neon glows on interactive elements.
- Ensure all content sections are clearly structured with adequate spacing.
- Maintain consistency in design patterns across all pages.
